# 🎲 UD01 – Actividad 06: Adivina el número

## 🎯 Objetivos

* Desarrollar un juego de consola en Kotlin en el que el programa genera un número aleatorio y el usuario debe adivinarlo.
* Trabajar con números aleatorios, entrada de datos por teclado, estructuras condicionales y bucles.
* Implementar un contador de intentos que se muestre al finalizar la partida.
* Validar la entrada del usuario para que el programa no falle con valores incorrectos.
* Controlar la ejecución del programa mediante un bucle que no termine hasta que se cumpla una condición (acertar el número).

## 🛠️ Tecnologías

* Kotlin
* IntelliJ IDEA
* Git y GitHub

## 📋 Requisitos del Proyecto

* Proyecto de tipo aplicación de consola llamado `UD01_Actividad06_AdivinaNumero`.
* Generar un número secreto aleatorio entre 1 y 100 que no se muestre durante la partida.
* Indicar tras cada intento si el número secreto es mayor, menor o igual al introducido.
* Contar los intentos y mostrar el total al acertar.
* Validar que el valor introducido sea un número entero entre 1 y 100, rechazando negativos, valores superiores a 100 y textos no numéricos.
* No finalizar el programa hasta que el usuario acierte.
* Mostrar mensajes claros y comprensibles.
